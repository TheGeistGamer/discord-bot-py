# Discord Welcome Bot

A simple Discord bot built with Python using `discord.py`.

This project automatically welcomes new members when they join the server and assigns them a default role. It also includes basic message commands such as `$hello` and `$ping`.

## Features

- Sends a welcome message when a user joins
- Automatically assigns a member role
- Basic text commands
- Uses environment variables with `.env`
- Beginner-friendly project structure

## Commands

- `$hello` → Replies with `Hello World!`
- `$ping` → Replies with `Pong!`

## Technologies

- Python 3
- discord.py
- python-dotenv
